# 代码审查遗留项基础加固实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 收口遗留审查中的运行时数据版本、构建环境和素材下载可靠性问题，并验证临时目录已经受到仓库规则保护。

**Architecture:** 运行时数据生成器从 `data/master/dataset.json` 读取唯一版本来源，将 `contentVersion`、`updatedAt` 和 `sourceSnapshot` 写入生成的 dataset metadata；小程序不再维护未使用的硬编码 dataset 全局状态。素材下载器保留批量并发，但在批次之间通过可测试的 sleep 注入固定延迟与随机抖动，并为源站请求设置明确的 User-Agent。Node/npm 版本范围由 `package.json` engines 固定，测试临时目录由既有 `.gitignore` 规则守护。

**Tech Stack:** TypeScript、Node.js `node:fs`/`fetch`、Vitest、npm、微信小程序生成数据。

## Global Constraints

- 不新增、删除或升级依赖。
- 不修改 `archive/`、`data/master/` 的数据内容或 `miniprogram/generated/` 生成文件；生成文件只能由 `npm run data:generate` 更新。
- 所有新增注释、文档和测试描述使用中文；保留必要的 API、文件名、命令和变量名英文。
- 不修改当前工作区的 UI 对齐 WXSS 与其契约测试文件；这些并发变更均不纳入本计划。
- 逻辑改动遵循先写失败测试、再实现、最后重构的 TDD 顺序。

### Task 3: 加固素材下载批次间隔和请求身份

**Files:**

- Modify: `tools/asset-pipeline/download-assets.ts`
- Create: `tests/asset-pipeline/download-assets.test.ts`

**Interfaces:**

- `DownloadAssetsOptions` 提供可选 `fetcher`、`sleep`、`random`、`batchDelayMs`、`batchDelayJitterMs` 和 `userAgent`，生产默认值分别使用全局 fetch、真实定时器、`Math.random`、100ms、50ms 和固定 User-Agent。
- `downloadAssets(entries, existingManifest?, options?)` 只在还有下一批时等待；每个请求通过 `headers['user-agent']` 发送固定身份。

- [x] **Step 1: 写跨批次延迟与 User-Agent 失败测试。**

使用 9 个临时本地路径和注入的 fake fetch，令第一批 8 个请求、第二批 1 个请求全部返回二进制响应；注入 `sleep` 和 `random: () => 0`，断言只等待一次且等待 100ms，并断言每个请求都带测试指定的 User-Agent。

- [x] **Step 2: 运行失败测试。**

Run: `npx vitest run tests/asset-pipeline/download-assets.test.ts`

Expected: 当前 `_BATCH_DELAY_MS` 未被使用，sleep spy 不会收到跨批次调用，测试失败。

- [x] **Step 3: 实现可测试的批次节流。**

将 `_BATCH_DELAY_MS` 改为具名默认常量，增加 50ms 抖动上限；让 `downloadOne` 使用注入 fetcher 和 User-Agent；每个非最后批次在 `Promise.all` 完成后等待 `baseDelay + floor(random() * (jitter + 1))` 毫秒。保持失败 manifest、缓存判断和输出格式不变。

- [x] **Step 4: 运行素材下载回归。**

Run: `npx vitest run tests/asset-pipeline/download-assets.test.ts tests/asset-pipeline/setup-assets.test.ts`

Expected: 延迟、请求头、缓存和素材入口测试全部通过，不触发真实网络。
