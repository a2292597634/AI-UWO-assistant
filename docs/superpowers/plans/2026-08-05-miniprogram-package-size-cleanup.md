# 小程序包体与素材清理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 清除 CloudBase 迁移后遗留在 miniprogram/ 的业务图片，修正素材构建输出位置，并增加包体积门禁，使小程序主包稳定低于微信 4096KB 限制。

**Architecture:** 运行时只保留少量 miniprogram/assets/ui/ UI 素材，航海士头像和技能图标继续使用现有 CloudBase CDN URL。业务素材下载、压缩、发布清单和依赖索引全部放在 data/assets/ 或 archive/，不再写入 miniprogram/；生成器只把运行时数据和详情分片写入小程序目录。

**Tech Stack:** TypeScript、Node.js 文件系统 API、Vitest、Sharp、CloudBase CDN manifest、微信小程序原生目录结构。

## Global Constraints

- 禁止直接在 master 分支开发；执行分支使用 codex/phase-8-package-size-cleanup。
- archive/ 只读，不修改或删除 archive/voyage-tw-2026052501/raw-assets/。
- data/master/ 是唯一可手动维护的数据源；本任务不修改 data/master/。
- miniprogram/generated/ 只能由 npm.cmd run data:generate 生成，禁止手动修改生成内容。
- miniprogram/ 运行时代码不得使用 wx.request、wx.cloud、远程 API 或 Node.js API。
- 不新增、删除或升级 npm 依赖。
- 不删除 CloudBase 云端对象，不重新上传已存在的 release，不修改现有 data/assets/cloudbase-manifest.json 的 release。
- 页面与运行时可见文本继续使用繁体中文。
- 提交前必须运行 npm.cmd run verify；commit 前展示变更文件、验证结果和拟用 message，等待用户确认。

**Safety checks before deletion:**

- [ ] Confirm git status --short --branch shows only the intended plan/code changes.
- [ ] Confirm each subpkg-a* directory contains only imgs/*.png and no runtime source.
- [ ] Confirm app.json has no subpkg-a* entry.
- [ ] Confirm non-generated runtime code has no references to the nine root PNG filenames.
- [ ] Confirm no CloudBase deletion command will be run.

Use an exact-path PowerShell cleanup, not a wildcard against the workspace root：

~~~powershell
$workspaceRoot = (Resolve-Path '.').Path
$legacyRoots = 0..9 | ForEach-Object { Join-Path $workspaceRoot "miniprogram/subpkg-a$_" }
$rootSamples = @(
  'officer_chasab001.png', 'officer_chast089.png', 'officer_chast096.png',
  'skill_skill100043.png', 'skill_skill203426.png', 'skill_skill300001.png',
  'skill_skill400591.png', 'skill_skill400973.png', 'skill_skill509998139.png'
) | ForEach-Object { Join-Path $workspaceRoot "miniprogram/assets/$_" }
$targets = @($legacyRoots + $rootSamples) | Where-Object { Test-Path -LiteralPath $_ }
foreach ($target in $targets) {
  $resolved = (Resolve-Path -LiteralPath $target).Path
  if ($resolved -notlike "$workspaceRoot\miniprogram\*") {
    throw "Refusing to remove path outside miniprogram: $resolved"
  }
}
foreach ($target in $targets) {
  Remove-Item -LiteralPath $target -Recurse -Force
}
~~~

删除后运行：

~~~powershell
npm.cmd run check:miniprogram-size
~~~

预期：主包低于 3.5MB，且不再报告 subpkg-a* 或根目录业务 PNG。
