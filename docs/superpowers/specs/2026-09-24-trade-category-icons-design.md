# 貿易品分類圖示設計

## 目標

為「貿易品淡旺季查詢」增加一套與參考圖同樣溫暖、帶柔和立體感的分類小圖示。全部 20 個貿易品分類都要有圖示，並在分類篩選按鈕和貿易品詳情的分類文字旁顯示。

詳情頁現有的貿易品個別圖示繼續顯示；分類圖示補充分類辨識，不取代商品圖，也不改變搜尋、篩選、導航、淡旺季資料或港口矩陣。

## 視覺方向

- 參照使用者提供的圖像：簡潔、可辨識的航海遊戲物件插畫，帶柔和的立體光影與細緻輪廓。
- 圖示採透明背景，不含文字、字母、徽章、外框或額外底板，讓底色由篩選按鈕和頁面承載。
- 20 個圖示使用一致的視角、比例、光源、描邊與陰影；以各類容易辨認的物件輪廓為主，縮小後仍能區分。
- 圖示在篩選區以約 `32rpx` 顯示，在詳情分類資訊中以約 `32rpx` 顯示；來源素材保留足夠像素以供不同裝置清晰縮放。

## 頁面呈現

### 分類篩選

- 20 個分類按鈕各自顯示本分類圖示與繁體中文名稱；「全部」是篩選選項，不屬於分類，不配置分類圖示。
- 保留現有選取狀態與點擊行為。圖示不依選取狀態改色，確保各狀態均能辨認。
- 篩選區改用 4 欄排列，圖示與名稱水平排列；按鈕最小高度調整為 `88rpx`，窄螢幕不得讓分類名稱溢出或造成頁面水平捲動。
- 使用既有 Design Foundation Token 和繁體中文，不新增全局樣式或依賴。

### 貿易品詳情

- 在既有分類名稱旁顯示相同的分類圖示。
- 商品本身的圖示、等級、淡旺季摘要與港口矩陣保持原樣。
- 分類文字仍是主要語義；分類圖示不取代文字，也不造成重複朗讀。

## 實作邊界

- 將 20 個本地圖示放在 `miniprogram/subpkg-trade/assets/category-icons/`，讓素材與貿易分包一同載入。
- 素材以兩位數分類 ID 命名為 `01.png` 至 `20.png`，避免檔名和資料 ID 映射漂移。
- 以一個可重用的本地映射函式按分類 ID 取得圖示路徑，供篩選頁和詳情 presenter 共用。
- 只修改分類圖示對應、篩選 WXML/WXSS，以及詳情分類 view state/WXML/WXSS；不改 `archive/`、`data/master/`、自動生成檔或既有商品素材管線。
- 不新增 `wx.request`、`wx.cloud`、外部 URL 或依賴。

## 驗收

- 20 個分類都對應到一張有效本地圖示；清單按鈕和詳情分類使用相同映射。
- 篩選選取、搜尋、商品圖示、詳情導航與季節矩陣行為不變。
- 在 320、375、393、430px 視寬檢視篩選列、長分類名稱、詳情分類列與水平溢出。
- 頁面變更遵循 `docs/superpowers/specs/2026-09-16-miniprogram-review-html-report-design.md`：開始時執行 `npm run devtools:doctor`，完成修改批次後產生迭代驗收報告，交付前執行最終頁面驗收並檢視 HTML 報告中的實際截圖。缺少修改後截圖或頁面驗收受環境阻塞時，須如實標示結果。
- 不修改既有使用者工作區變更；不提交任何檔案，除非使用者另行確認。
