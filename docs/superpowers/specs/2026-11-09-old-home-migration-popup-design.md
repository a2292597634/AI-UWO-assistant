# 舊端首頁遷移彈窗設計

舊端 AppID 為 `wx8f961bcd8b26996a`。用戶每次進入或返回舊端首頁，都看到已確認的 Demo 所示彈窗。彈窗遮住並停用首頁操作，沒有關閉按鈕，點背景也不能關閉。此設計在首頁生效。從既有分享卡片直接進入其他頁面的用戶，在回到首頁時才看到彈窗。

彈窗標題為「請前往『起源航海小助手』」，說明為「新版已上線，請前往新版繼續使用。舊版的艦隊配置與提醒設定不會自動帶到新版。」唯一按鈕為「前往新版」。舊端首頁被鎖住後，使用者也無法從該首頁進入舊配置或提醒相關頁面。

由按鈕點擊呼叫 `wx.navigateToMiniProgram`，固定使用新端 AppID `wxd0bc7afdc9cd334a`、`envVersion: 'release'`，省略 `path` 以開啟新端首頁。呼叫期間防止連點。微信確認取消後回到遷移彈窗。其他失敗在彈窗內提示重試或在微信搜尋「起源航海小助手」。用戶從新端返回舊端時，仍顯示遷移彈窗。

實作以舊端維護分支為基線，放在獨立候選分支。變更範圍為舊端首頁的 WXML、WXSS、TS 和必要驗收場景。跳轉只傳固定 AppID 與環境，不傳用戶資料。

候選在 Node 22 下執行倉庫門禁，並按首頁驗收規範記錄彈窗、窄屏、按鈕與底層功能不可操作的截圖。用一般微信帳號在真機核對取消後保留彈窗、確認後開啟新端正式版，以及返回舊端時仍顯示彈窗。提交前展示檔案、驗收結果與擬用訊息，按 AGENTS.md 取得確認。上傳及正式發布依雙端維護手冊分開處理。
