# 大流行可能進行事件與精簡海域矩陣設計

## 背景

大流行遊戲時刻表修正後，Domain 的一般預測仍採 `[now, now + horizon)`，所以已在 `now` 前觸發、但按遊戲規則最多可能持續兩小時的大流行不會出現在目前矩陣。頁面也仍列出目前七時段沒有任何事件的海域，造成矩陣冗長。

使用者確認採用以下規則：在目前時段補充可能仍持續的候選事件，並隱藏目前矩陣範圍內沒有事件的海域。這是對先前「不回看過去事件」規則的窄例外；不把普通過去事件加回行程或其他矩陣時段。

## 設計決策

### 可能進行事件

- 一般未來預測維持既有半開區間 `[now, now + horizon)`，週期、相位、延遲、優先順序、區域與類型篩選都不變。
- Domain 增加獨立的候選查詢，沿用相同週期公式及最多兩種重疊事件規則，尋找觸發時間滿足 `triggerAt > now - 7200` 且 `triggerAt < now` 的事件。
- 只有目前 UTC+8 整點槽可接收這些候選。候選不顯示在其他矩陣頁段，也不加入行程列表或下一次事件搜尋結果。
- 候選事件在矩陣標示「可能進行」；點開詳情仍顯示來源推算的實際觸發日期和時間。
- 合併目前槽的候選與未來事件後，按事件唯一鍵去重；同一海域最多顯示兩種，沿用來源等待週期由長至短的優先順序。
- 恰好在 `now - 7200` 觸發的事件不納入，因其已達遊戲規則的兩小時最長持續時間。
- 過去候選與未來預測以事件唯一鍵去重。海域、事件類型篩選同時套用於兩者。

因為小程序沒有城鎮活動或事件預算的即時資料，候選事件可能已提早結束或實際未發生。介面只說「可能進行」，不顯示已確認的即時狀態。

### 海域矩陣精簡

- 對目前可見的七槽頁段，套用篩選後只顯示至少一個槽有事件的海域。
- 不因指定海域在其他頁段有事件而回退顯示目前沒有事件的所有海域。
- 時間欄頭獨立於海域列產生；即使本段沒有任何符合條件的海域，也要保留七槽欄頭與目前時段高亮。
- 當本段無符合條件的海域時，顯示「此七個時段暫無預測」訊息；既有整體範圍空狀態仍只表示整段預測範圍完全沒有符合條件的事件。
- 行程列表、24 小時／3 天／7 天範圍、日期導覽、事件詳情、素材與圖示行為不變。

## 資料邊界

- 不修改 `archive/`、`data/master/major-events.json`、來源錨點、事件週期、海域相位、延遲或交易品映射。
- 一般未來預測仍嚴格使用 `[now, now + horizon)`。過去兩小時查詢只用來產生目前矩陣槽的候選，不是一般歷史列表。
- 不推算城鎮活動是否阻擋事件，也不推算預算是否已耗盡；兩者只用於提示候選狀態的不確定性。

## 驗收

### Domain 與 Presenter

- 固定 `2026-09-25T10:47:00+08:00` 時，北極海 `09:06:30` 戰爭出現在 `10:00` 目前槽，標記「可能進行」；同事件不出現在 `09:00` 過去槽或行程列表。
- 觸發時間恰為 `now - 7200` 或更早的事件不作為候選；未來事件仍依既有左閉右開邊界顯示。
- 相同事件不重複顯示；同一海域目前槽內合併候選與未來事件後最多兩種，依來源優先順序保留。

### Page 與 DevTools

- 未選海域時只顯示目前七槽內至少有一個事件的海域；選定海域或事件類型後，空結果不回退顯示其他海域。
- 本段沒有事件時仍顯示時間欄頭、目前時段底色和明確的本段空狀態。
- 事件候選詳情保留實際觸發時間並說明可能已結束或未發生；未來矩陣、行程、範圍導覽及查下一次維持原行為。

### 工程檢查

- Domain 邊界使用紅—綠—重構測試；頁面狀態以 DevTools 場景及 HTML 截圖報告驗收。
- 執行 `npm run verify`、`npm run devtools:doctor`、DevTools iterate/final 和 `git diff --check`。
- 不新增依賴或執行時網路呼叫，不改動生成資料與交易品圖示。
