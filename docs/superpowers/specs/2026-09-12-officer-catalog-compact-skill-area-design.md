# 航海士名鑒技能區緊湊化設計

## 目標

針對航海士名鑒頁的實際截圖問題，縮短由技能入口區撐出的行高，減少技能圖標之間與圖標上下方的視覺空白，讓列表密度更接近戰鬥配對頁的技能目標行。

## 根因

目前 `.catalog-page__officer-skills`、`.catalog-page__officer-skills-content` 與每個 `.catalog-page__skill-hit-target` 都使用 88rpx 高度。技能圖標本身只有 44rpx，導致實際內容高度主要由透明操作熱區決定；航海士名稱、職業／性別與技能區垂直堆疊後，行的實際高度仍明顯高於頭像，頭像下方因此留下大段空白。

## 設計方案

- 只在航海士名鑒頁的技能入口區採用緊湊尺寸：技能滾動區、內容軌道與單個技能入口統一改為 64rpx 高度；單個入口寬度也改為 64rpx。
- 保留共享 `skill-icon` 元件的 44rpx 視覺圖標、等級角標、橫向滾動、技能詳情事件與 WXML 結構不變。
- 保留既有 `--uwo-space-1` 圖標間距與分隔線間距，不引入硬編碼的新間距值。
- 這是使用者明確接受的名鑒頁局部緊湊例外，不修改全局 Design Foundation，也不影響其他頁面或共享操作元件。
- 更新名鑒頁現有靜態契約測試，將此頁的技能入口尺寸契約由 88rpx 改為 64rpx，並保留 `role="button"` 與 `catchtap="onSkillIconTap"` 的交互契約。

## 範圍

- 修改 `miniprogram/pages/catalog/index.wxss`。
- 修改 `tests/pages/catalog-page.test.ts`。
- 新增本次變更的設計與執行計畫文檔。
- 不修改資料、生成檔、共享 `skill-icon` 元件、其他頁面、遠程請求或依賴。

## 驗收

- 航海士行高度較目前版本明顯縮短，頭像下方不再有大段空白。
- 技能圖標視覺尺寸保持 44rpx，圖標相鄰空隙與上下空白明顯縮小。
- 320px、375px、393px、430px 寬度下，技能圖標不裁切，主動／被動分隔線仍清楚，列表不新增頁面級橫向溢出。
- 技能圖標仍可點擊查看技能詳情。
- 相關契約測試、`npm run verify` 與 `git diff --check` 通過。
