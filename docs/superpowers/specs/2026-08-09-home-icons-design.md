# P8 首頁與圖標資產設計規格

## 目標

在不改變首頁導航、資料來源、航海士編輯頁校驗與保存流程的前提下，收口首頁首屏密度，補齊戰鬥配隊、冒險配隊與資料維護的正式模組圖標，並讓四個入口沿用同一套寫實黃銅航海徽章語言。

## 已確認的設計決策

### 首頁層級

- 港口 Hero 保留現有 `/assets/ui/home-harbor.jpg` 與港口航海主題，高度由 `320rpx` 收斂到 `240rpx`。
- 首要模組入口為「航海士名鑑」、「戰鬥模擬艦隊」和「冒險模擬艦隊」；三者保留現有路由。
- 原「新增航海士」入口改名為「資料維護」，仍指向 `/pages/officer-editor/index`，但移到次級入口區，視覺權重低於三個主要模組。
- 所有入口仍由首頁資料陣列驅動，不改變 Controller、資料來源或導航行為。

### 圖標資產

- 現有「航海士名鑑」圖標是寫實黃銅 PNG，因此新增三個圖標也使用同一方向的生成位圖，不改繪既有圖標。
- 三個主源文件放在 `data/master/ui-assets/`，由現有 UI Asset Pipeline 輸出到 `miniprogram/assets/ui/`。
- 圖標生成要求：透明背景、居中徽章構圖、寫實黃銅與墨綠材質、清晰外輪廓、無文字、無 Logo、無水印、無人物臉部和現代物件。
- 生成工作使用已登入的 ChatGPT 內置瀏覽器網頁端；生成完成後下載到項目主源目錄。若瀏覽器、登入或下載失敗，必須停止並報告，不以占位文件冒充完成。
- 每個運行圖標輸出為 `96×96` PNG，單個不超過現有 `12KB` feature budget；生成主源不進小程序包。
- 圖標載入失敗時使用現有黃銅 CSS 線稿占位，不使用 Emoji、Unicode 或首字占位。

### 視覺與布局

- 新增或修改 WXSS 使用 Design Foundation Token，樣式類名使用英文 BEM。
- Hero 仍使用展示性標題字體；正文、模組名稱和次級入口使用系統無襯線字體。
- 重要入口保留至少 `88rpx` 觸控熱區；模組圖標只增強辨識，文字名稱仍是完整語義。
- 不新增整頁背景、持續動畫、大型裝飾或遠程素材。
- 320/375/393/430px 寬度不得產生頁面級橫向溢出。

## 資料與構建邊界

首頁模組只保存既有 `id`、繁體中文名稱、圖標路徑、路由和圖標錯誤狀態。素材配方繼續由 `tools/ui-assets/config.ts` 統一管理；構建器繼續輸出確定性報告、校驗透明邊界和總體積。不得修改 `archive/` 或 `miniprogram/generated/`，不新增網絡請求、Node.js Runtime API 或依賴。

## 驗證

- 素材構建測試確認三個新增配方會被處理、輸出尺寸和 byte budget 正確，構建結果保持確定性。
- 首頁測試確認三個主要入口與一個資料維護次級入口均使用本地圖標路徑，資料維護使用既有編輯路由，WXML 不含 Emoji/Unicode 功能圖標回退。
- 手動驗收檢查 Hero 高度、三個主要入口與資料維護層級、載入失敗降級、320/375/393/430px 寬度與橫向溢出。
- 階段完成前執行 `npm.cmd run verify` 與 `git diff --check`，並檢查禁止目錄沒有變更。
