# 冒險與戰鬥配隊頂部配置卡參考圖重建設計

日期：2026-09-19
狀態：待使用者審閱
範圍：`config-bar` 的突出配置／分享變體，以及冒險配隊與戰鬥配隊頁面的頂部接線

## 1. 背景與目標

目前兩個配隊頁已共用配置與分享入口，但實際視覺仍偏向一般表單卡片，與參考圖中的暖白紙張卡、深色分享票據和柔和層次差距明顯。本次重建以參考圖為唯一視覺基準，使用當前小程序模擬器的 `iphone-small` 尺寸作為像素校準基線，再檢查其他裝置的響應式退化。

目標：

- 冒險配隊與戰鬥配隊使用完全相同的頂部配置卡結構、尺寸與視覺層級。
- 把配置入口和分享入口重建為同一張暖白紙張卡中的左右雙欄：左側配置資訊，右側深色分享票據。
- 還原參考圖的紙張／毛玻璃觀感：低對比本地紙張紋理、半透明淺色層、內描邊、高光邊界與既有陰影 Token。
- 讓配置名稱成為主視覺，狀態、套數與分享輔助文字形成清楚但不喧賓奪主的層級。
- 保留現有展開、保存、命名、分享、載入、禁用與無障礙語義，不修改下方船隻、技能、目標、總覽或分享預覽內容。

## 2. 非目標與邊界

- 不修改配隊資料、分享圖生成資料、CloudBase、依賴或頁面下半部內容。
- 不把頂部卡片做成單張不可互動圖片；配置與分享仍必須是真實 WXML 控件。
- 不新增遠程素材、遠程字體或運行時網路請求。
- 不為了參考圖改動系統級微信導航列；只校準頁面自身的上下文標題和配置／分享區域。

## 3. 視覺方案

### 3.1 外層紙張卡

`config-bar--prominent-share` 是單一頂部控制容器，使用現有 `surface`、`surface-muted`、`border-subtle`、`border-strong`、`radius-card` 和 `shadow-elevated` Token。容器加入一張低對比、無文字無插畫的本地紙張紋理，並以半透明淺色覆蓋層控制對比度，避免紋理干擾正文。

在 `iphone-small` 基線下，外層卡片以約 `248rpx` 的總高度、`space-3` 內距和 `space-3` 欄間距建立參考圖相近的縱向比例；高度不得依賴頁面下方內容撐開。外層保留雙層邊界：外圈使用較深邊界，內圈使用 `surface` 高光線；不新增硬編碼色值。

### 3.2 左側配置欄

左欄為可點擊的完整配置入口，佔用剩餘寬度，右側固定分享欄寬度。內部維持兩行結構：

1. 上行：`我的配置`、保存狀態 Chip。
2. 下行：配置名稱、套數和右側折疊箭頭。

配置名稱使用 `page-title` Token 與 `700` 字重，讓「未命名配置」在視覺上接近參考圖；標籤使用 `body` 或 `supporting` Token，套數至少保持 `body` Token，獨立操作文字不低於 `22rpx`。文字不可因長名稱破壞右側分享欄，使用省略處理。

### 3.3 右側分享票據

分享入口是固定寬度的深色直向票據，使用 `ink` 背景、`surface` 文字、`accent-brass` 輔助提示與同一組控制圓角。比例以參考圖為準，寬度約 `176rpx`、高度與左欄一致；分享圖形、主標「分享」和輔助「生成分享圖」垂直置中，圖形尺寸比目前版本放大一級。

生成中、錯誤和禁用狀態沿用既有狀態語義：禁用改用 `surface-muted`、`text-secondary` 和 `border-subtle`，不能只依賴透明度或顏色表達。

### 3.4 頁面上下文

冒險和戰鬥頁都保留現有 `fleet-context` 資訊，只調整其與配置卡的垂直節奏和視覺銜接，使配置卡看起來是頁面頂部的主控制區。船隻頁籤、船位、目標、技能、總覽與底部導航不修改。

## 4. 素材與程式結構

- 新增素材源：`data/master/ui-assets/config-paper-texture-source.png`。
- 生成素材：`miniprogram/assets/ui/config-paper-texture.png`，由既有 UI asset pipeline 產出並納入 manifest。
- 共享結構仍集中在 `miniprogram/components/config-bar/index.wxml` 與 `index.wxss`；不為兩個頁面複製兩份配置卡樣式。
- 頁面只保留 `prominent-share="{{true}}"` 和必要的布局接線；互動事件、資料欄位與分享預覽流程不變。

## 5. 驗收標準

### 視覺驗收

- `iphone-small` 的冒險與戰鬥頂部截圖中，兩頁卡片外框、左欄、分享票據的幾何比例一致。
- 配置名稱、狀態 Chip、套數、分享圖形和輔助文字的基線與層級接近參考圖，不出現目前版本的扁平純色塊感。
- 紙張紋理只提供低對比材質，不遮擋正文；外框可見內外兩層邊界與柔和層次。
- 卡片下緣與下一個頁面區域的間距穩定，不能因配置卡高度造成船位或技能區域錯位。

### 行為與品質驗收

- 冒險與戰鬥頁的配置入口、展開／收起、分享、生成中、錯誤和禁用狀態均可操作。
- 既有元件契約、頁面測試、UI asset check、runtime network check 與完整 `npm run verify` 通過。
- 兩個分享場景各至少產生一張修改後頂部截圖，並在 HTML／Markdown 驗收報告中可查看。
- `git diff --check` 通過；不提交使用者既有的 `artifacts/` 與未跟蹤文件。

## 6. 後續實施順序

1. 先按本設計建立實施計畫與最小素材規格。
2. 生成並登記低對比紙張紋理，確認資產檢查通過。
3. 重做共享 `config-bar` 的突出變體與兩頁頂部節奏。
4. 更新契約測試和驗收場景，連接開發者工具截圖。
5. 以 `iphone-small` 逐輪調整，再檢查 `iphone-standard` 與 `android-large`。
