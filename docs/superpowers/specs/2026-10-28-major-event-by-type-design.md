# 大流行按流行查詢設計

## 已確認的介面

使用者已逐輪確認互動 demo，最後確認緊湊的四欄兩列「小圖示＋名稱」按鈕，以及各海域使用自身既有徽記的時間列表。新增「按流行」檢視，保留原時刻矩陣、日程列表和預設矩陣。所有介面使用繁體中文。

## 行為

- 八種流行單選，預設奢侈；可選全部海域或單一海域。
- 每個海域只列所選流行從目前時間起的下一場，按開始時間排序，同時刻按既有海域順序。
- 獨立查詢既有 379 小時搜尋窗，不受 24 小時／3 天／7 天選項限制；進入此檢視時隱藏範圍控制。
- 初始顯示五個海域，可展開全部或收起；改選類型、海域時收回五項。分鐘刷新及回前景保留選擇和展開狀態，更新日程與倒數。
- 顯示東八區日期、時刻、距離開始時間；沿用既有分鐘顯示規則與詳情浮層。查無結果顯示空狀態，不偽造日程。
- 沿用週期、錨點、海域相位／延遲與最多兩種同時事件的順序規則，保留城鎮活動與事件預算說明，不宣稱即時狀態。

## 實作與資源

Domain 增加批次查詢每個海域下一場的純函數，重用既有排程及排序。獨立 Presenter 將下一場轉為日期、倒數和既有交易品類詳情；頁面只處理視圖、篩選、展開和圖示降級。海域徽記直接沿用 runtime 參照資料，不新增網路請求。

流行小圖示採用本地 SVG 主源與現有大流行素材生成流程產生 PNG，保持可重現建置；不新增依賴。新增樣式遵循 Design Foundation Token、88rpx 熱區、窄屏及安全區要求，列表內容為視覺主體。

## 驗收與保護

先紅後綠驗證下一場唯一性、排序、超過七天、開始邊界、同時事件優先序、篩選、刷新、詳情和圖示降級。使用現有微信 DevTools 場景產生 HTML 報告，區分頁面、倉庫門禁及真機狀態。既有 dirty／untracked 內容先記錄 SHA256，不修改無關文件；本任務不 commit、不 push、不部署。
