# 航海士名鑒列表密度與技能圖標間距調整設計

## 目標

降低航海士名鑒頁每筆航海士資訊的垂直留白，讓列表資訊密度接近戰鬥配隊頁的技能目標行，同時保留技能圖標可操作性與既有視覺層級。

## 範圍

- 只修改 `miniprogram/pages/catalog/index.wxss`。
- 只影響航海士模式的 `.catalog-page__officer-row` 與其技能圖標區。
- 不修改 WXML 結構、資料、互動邏輯、共享 `skill-icon` 元件或其他頁面。

## 現況與問題

- 航海士行目前使用 `--uwo-space-4`（16rpx）四側內距，行的最小高度為 132rpx。
- 航海士資訊與技能區之間使用 `--uwo-space-2`（8rpx）間距。
- 每個技能圖標外層為 88rpx × 88rpx，實際圖標為 44rpx；外層熱區較大是為了保留獨立操作的觸控空間，但相鄰圖標與組間留白仍可收窄。
- 戰鬥配隊技能目標行採用 `--uwo-space-2` 垂直內距與較小的圖標間距，可作為本次密度調整的參考。

## 設計方案

1. 航海士行的上下內距改為 `--uwo-space-2`（8rpx），左右內距維持 `--uwo-space-4`（16rpx），避免壓縮文字與頭像的水平可讀空間。
2. 航海士行最小高度調整為 124rpx，與 104rpx 頭像及上下 8rpx 內距的內容尺寸一致。
3. 航海士資訊與技能區的上方間距改為 `--uwo-space-1`（4rpx）。
4. 保留每個技能圖標外層 88rpx × 88rpx 熱區，不縮小可點擊範圍；僅將圖標間、更多數量標記與主動／被動分隔線的非必要間距改為 `--uwo-space-1`（4rpx）。
5. 維持技能圖標本身尺寸、等級標籤、橫向滾動與點擊事件不變。

## 驗收

- 航海士列表每行上下留白比現況更緊湊，頭像與文字不被裁切。
- 技能圖標仍能獨立點擊，且保留 88rpx 操作熱區。
- 主動／被動技能分隔仍清楚，橫向滾動與技能詳情行為不變。
- `git diff --check` 通過，相關測試與專案完整驗證不引入由本次 WXSS 修改造成的錯誤。
