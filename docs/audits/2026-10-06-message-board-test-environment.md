## 已完成的只讀核對

- 本機 CloudBase CLI 3.7.0，支援 env create／list／detail。
- env create 的程式實際會先選購買時長與續費；「無參數返回套餐」的說明不能當作非交互安全承諾。
- 核對原碼後，以缺少 alias／package 的非交互命令查套餐；它在讀取價格後以 MISSING_PARAM 退出，沒有進入 CreateEnv。
- 最低可選 CLI 套餐為 baas_personal，上海地域、1 個月，目前 RealTotalCost 對應 19.90 元，資源點 40,000；CLI 清單不包含免費選項。
- CLI 內部 PackageAllowList 只顯示三種付費套餐。因此沒有免費選項不能證明帳號一定沒有免費资格。
- 正式環境的只讀詳情顯示個人版、prepayment、上海地域；這些欄位不足以判定免費體驗資格，不把它當作無免費資格的證據。
- 已登入控制台並備妥零元方案，兌換碼缺失使建立按鈕停用；沒有替使用者接受服務條款或購買。

## 微信關聯與後續條件

官方建立環境指南指出，微信開發者工具建立的環境會自動關聯目前小程序；腾讯雲側環境可能需要在微信端「使用已有腾讯云环境」完成轉換／扫码驗證。因此環境建立成功不等於微信 SDK 或 openapi 已可用。

建立後需要確認新環境的微信歸屬、SDK／runtime、HTTP callback 分流及 timer 來源。若平台要求本人扫码完成关联，交由使用者在平台操作，不傳送密鑰到聊天、不假造來源校驗通過。

G0 三門檻依然 not-run；本地 35 項測試與完整 verify 通過的紀錄保持，不改成真雲通過。
