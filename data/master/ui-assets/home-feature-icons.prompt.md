# 首頁功能入口圖標 A 方向生成記錄

生成工具：Codex 內建 ImageGen。七枚素材均為單獨生成的透明底道具插畫，不使用外部圖片或遠程 URL。A 方向取自使用者選定的「獨立物件剪影」方案：以不同物件輪廓表示功能，沿用航海貿易 RPG 道具圖標的手繪立體質感，不使用共用徽章、底牌或邊框。

## 共用風格與正規化

- 暖羊皮紙、深色木材、黃銅與少量深海綠／暗紅點綴；物件有清楚暗色輪廓和柔和立體陰影。
- 每枚圖標都是獨立道具，透明背景；不含功能文字、數字、Logo 或浮水印。
- 原圖依可見 alpha 範圍裁切，置中正規化至 320×320 透明畫布；既有 UI Asset Pipeline 輸出 96×96、16 色 PNG，可見主體約佔 86×86。
- 不改變首頁入口順序、名稱、路由或版面。
